# Telegram search bot
1. Создай бота через @BotFather.
2. Залей файлы в приватный GitHub-репозиторий.
3. Render: Web Service, Build `pip install -r requirements.txt`, Start `python bot.py`.
4. Environment Variable: `BOT_TOKEN=токен`.
5. В Telegram отправляй боту `.txt`, `.csv`, `.json` или `.log`, затем выбирай Username/номер/ID.
Не публикуй токен или базы в GitHub.
